# AgentBaiting

Supporting indicators for **AgentBaiting: How 800+ Fake AI Skills and MCP Servers Delivered Malware**.

## Dataset

[`malicious-repositories-and-zip-hashes-2026-07.csv`](malicious-repositories-and-zip-hashes-2026-07.csv) contains the GitHub repository URL and SHA-256 hash of each associated ZIP archive.

| Column | Description |
| --- | --- |
| `repository` | Full GitHub repository URL |
| `zip_sha256` | SHA-256 hash of the associated ZIP archive |
